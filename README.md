# SmartSpeed for YouTube (Chrome / Vivaldi Extension)

Eine Browser-Erweiterung (Manifest V3) für Chromium-basierte Browser (Chrome, Vivaldi, Brave, Edge), mit der für verschiedene YouTube-Kanäle individuelle Wiedergabegeschwindigkeiten automatisch eingestellt und gespeichert werden können.

## Highlights
- **Kanalbasierte Geschwindigkeit**: Automatische Anpassung der Geschwindigkeit je nach Kanal (z. B. 1.3x für Sprech-Kanäle, 1.0x für Musik).
- **Manifest V3 Kompatibilität**: Volle Unterstützung für Vivaldi & Chrome.
- **Popup-zentrierte Steuerung (MVP)**: Einstellungen und Kanal-Speicherung bequem über das Extension-Popup steuerbar (keine störenden UI-Injektionen in die YouTube-Website).
- **Robuste SPA-Navigation**: Erkennt Videowechsel & Kanalnamen dynamisch aus dem Live-DOM ohne Neuladen der Seite.
